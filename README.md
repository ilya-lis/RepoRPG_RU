# RepoRPG_RU

Русификатор мода [RepoRPG](https://thunderstore.io/c/repo/p/ExtraCreamyMilk/RepoRPG/) (R.E.P.O.), для версии 1.0.100.

- **Готовый архив:** [`release/RepoRPG_RU-0.1.0.zip`](release/RepoRPG_RU-0.1.0.zip) - ставится через «Import local mod» в менеджере модов или вручную.
- **Описание для игроков** (установка, настройки, что переведено): [`mod/README.md`](mod/README.md).

> Версия 0.1.0 проверена только на стенде сборки, в самой игре - ещё нет.

## Как устроено

Мод не рассчитан на перевод: тексты зашиты в код, часть из них он сам же сравнивает, разбирает и пересылает по сети.
Поэтому русификатор состоит из двух частей.

- **`RepoRPG_RU.Patcher.dll`** (`src/Patcher`) - запускается до загрузки модов и делает переведённую *копию* `RepoRPG.dll`;
  оригинал не трогает. Строку заменяет только там, где она точно идёт на экран: ключи, имена настроек, тексты для журнала,
  тексты, по словам которых мод что-то проверяет, и всё, что отправляется другим игрокам, остаются как были.
- **`RepoRPG_RU.dll`** (`src/Runtime`) - переводит в момент вывода на экран то, что нельзя заменить в коде: слова,
  которые мод использует и как внутренние имена, фразы, собранные из частей, сообщения от хоста.

Что можно и что нельзя трогать в коде, описано в `mod/RepoRPG_RU.rules` (создаётся `tools/genrules.py`).

## Перевод

Исходники перевода - `translation/ru/*.tsv` (номер строки из `translation/units.json` и русский текст; `extra.tsv` -
слова и фразы, добавленные вручную). Из них `tools/mkpo.py` собирает `mod/lang/RepoRPG_RU.po` - этот файл и читает игра.

    python3 tools/mkpo.py translation/units.json translation/ru mod/lang/RepoRPG_RU.po

Полезное при переводе: `tools/listing.py` (что ещё не переведено), `tools/peek.py` (строка и код вокруг неё),
`tests/langcheck.sh "English text"` (как эта фраза будет выглядеть на экране).

## Сборка и проверка

Нужны bash, python3 и доступ в интернет при первом запуске (компилятор и Mono.Cecil скачиваются в `~/.cache/rtk`).

    bash tools/pack.sh        # сборка и архив в release/
    bash tests/run.sh         # патчер на учебном моде: 15 сценариев
    bash tests/stress.sh      # патчер на большой настоящей сборке
    bash tests/langcheck.sh   # словарь: каждая переведённая строка и фразы из tests/drawn.tsv

## Что дальше

1. Проверка в игре; файлы `report.txt`, `untranslated.txt` и `LogOutput.log` после первого запуска.
2. Перевод встроенных данных мода - нужен сам `RepoRPG.dll` либо папка `dump` (см. `mod/README.md`, «Помощь переводу»).
3. Описания параметров в файле настроек, вкладка Debug.

Файл `*.blob` в корне - декомпилированный исходник мода, по которому делался перевод. Он принадлежит автору мода;
в архив русификатора не входит.
