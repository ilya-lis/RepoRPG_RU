# RepoRPG_RU

Русификатор мода [RepoRPG](https://thunderstore.io/c/repo/p/ExtraCreamyMilk/RepoRPG/) (R.E.P.O.), для версии 1.0.100.

- **Готовый архив:** [`release/RepoRPG_RU-0.2.3.zip`](release/RepoRPG_RU-0.2.3.zip) - ставится через «Import local mod» в менеджере модов или вручную.
- **На Thunderstore:** <https://thunderstore.io/c/repo/p/Ilya_lis/RepoRPG_RU/> - как выложить новую версию, см. ниже.
- **Описание для игроков** (установка, настройки, что переведено): [`mod/README.md`](mod/README.md).
- **Что изменилось:** [`mod/CHANGELOG.md`](mod/CHANGELOG.md).

> Версии от 0.1.0 до 0.2.2 запускались в игре (R.E.P.O. 0.5.3, Unity 6000.3.17): мод с русификатором загружается и
> работает, ошибок в журнале нет; шрифт меню подключается начиная с 0.2.2 (см. «Шрифт меню» ниже). Версия 0.2.3
> переводит слова самой игры так же, как её официальный русский перевод (см. «Слова самой игры»), и проверена на стенде
> сборки.

## Как устроено

Мод не рассчитан на перевод: тексты зашиты в код, часть из них он сам же сравнивает, разбирает и пересылает по сети.
Поэтому русификатор состоит из двух частей.

- **`RepoRPG_RU.Patcher.dll`** (`src/Patcher`) - запускается до загрузки модов и делает переведённую *копию* `RepoRPG.dll`;
  оригинал не трогает. Строку заменяет только там, где она точно идёт на экран: ключи, имена настроек, тексты для журнала,
  тексты, по словам которых мод что-то проверяет, и всё, что отправляется другим игрокам, остаются как были.
- **`RepoRPG_RU.dll`** (`src/Runtime`) - переводит в момент вывода на экран то, что нельзя заменить в коде: слова,
  которые мод использует и как внутренние имена, фразы, собранные из частей, сообщения от хоста, а также все названия
  и описания из данных мода.

Что можно и что нельзя трогать в коде, описано в `mod/RepoRPG_RU.rules` (создаётся `tools/genrules.py`); каждый раздел
этого файла объяснён в нём самом.

**Шрифт меню.** Мод рисует меню шрифтом игры (Teko), в котором нет кириллицы, - русские буквы берутся из системного
шрифта и почти вдвое шире латинских. `mod/font/RepoRPG_RU.ttf` - это Teko с добавленной кириллицей (собирается
`tools/mkfont.py` из Teko и Sofia Sans Extra Condensed, оба под SIL OFL 1.1). Патчер ставит в начало метода, где мод
выбирает шрифт (раздел `[font]` правил), вопрос к `RepoRPG_RU.dll`; та добывает шрифт, измеряет несколько букв и отдаёт
его моду, только если ширины совпали с записанными при сборке (`RepoRPG_RU.ttf.check`), - иначе мод выбирает шрифт сам,
как раньше (`src/Runtime/Fonts.cs`).

Как добыть шрифт, выяснилось на игре (Unity 6000.3.17, `font.txt` версии 0.2.1): `new Font(путь)` даёт объект без
единого знака и «не динамический» - так загружала версия 0.2.1, и шрифт не подключился; а по имени шрифт находится,
только если он установлен в Windows для всех пользователей. Свои шрифты игра хранит как готовые объекты `Font` с данными
шрифта внутри; такой объект получается из набора ресурсов (asset bundle). Его делает `tools/mkbundle.py`: берёт за
образец набор `modern.bundle` из [UniverseLib](https://github.com/sinai-dev/UniverseLib) (собран в Unity 2017.1, с
описаниями типов; сама библиотека загружает его в любой игре на Unity 2017 и новее), оставляет один шрифт с его
материалом и пустой текстурой и подменяет данные шрифта, имена и метрики на наши. Редактор Unity для этого не нужен.
Результат - `mod/font/RepoRPG_RU.bundle`; игра получает его байтами (`AssetBundle.LoadFromMemory`), так что путь к
файлу роли не играет.

Чего это не доказывает: набор сделан без редактора Unity, и принимает ли его Unity 6000.3, здесь проверить нечем. На
стенде его читает собственный разборщик формата (`tests/unity/AssetBundleModule.cs`), написанный отдельно от
`mkbundle.py`, - это проверка, что файл цел и внутри то, что задумано, а не проверка самого Unity. Ответ даст
`font.txt` из игры; если набор не подойдёт, остаётся установка `.ttf` в систему.

**Данные мода** (встроенные JSON: классы, перки, снаряжение, контракты) внутри мода остаются английскими: названия там
служат ключами, попадают в сохранения и уходят другим игрокам. Они переводятся при выводе на экран:

- текст с числами узнаётся по «форме» - числа в нём могут быть любыми (мод сам пересчитывает их по рангу таланта);
- название предмета («Rare Sharp Striker Module of the Brawler») разбирается на слова и собирается по-русски с
  согласованием: «Редкий острый ударный модуль драчуна»;
- только справочник (Guide) заменяется прямо в данных: его тексты никуда не передаются, а поиск по нему должен
  работать по-русски.

## Перевод

Исходники перевода:

- `translation/ru/part*.tsv` - строки из кода мода (номер из `translation/units.json` и русский текст);
- `translation/ru/data/*.tsv` - тексты из данных мода (номер из `translation/data.json`; у названий снаряжения после
  текста стоят формы: `|g=f` - род предмета, `|f=…|n=…|p=…` - формы прилагательного);
- `translation/ru/extra.tsv` - слова и фразы, добавленные вручную. В переводе фразы, которая собирается при выводе
  (`+pattern`), слово после числа можно дать в трёх формах: `{0} {0|осколок|осколка|осколков}`.

- `translation/official.tsv` - слова самой игры в её официальном русском переводе (см. ниже).

Правила и словарь терминов - в [`translation/glossary.md`](translation/glossary.md). Из исходников `tools/mkpo.py`
собирает `mod/lang/RepoRPG_RU.po` - этот файл и читает игра. Проще всего запускать сборку словаря вместе с проверкой:

    bash tests/langcheck.sh                      # собрать словарь и проверить его
    bash tests/langcheck.sh "Rare gear"          # как эта фраза будет выглядеть на экране

Полезное при переводе: `tools/listing.py` (что ещё не переведено в коде), `tools/data.py list` (то же для данных),
`tools/peek.py` (строка и код вокруг неё).

### Слова самой игры

С версии 0.5.0 у R.E.P.O. есть официальный русский перевод. Всё, что принадлежит игре - точка сбора, ценные вещи, фургон,
организатор, оживление, названия улучшений, имена монстров, - перевод мода называет её словами (с версии 0.2.3).

- Источник: таблицы строк игры, которые студия выкладывает для авторов модов, -
  [Semiwork-Studios-AB/REPOAssets](https://github.com/Semiwork-Studios-AB/REPOAssets), папка `Localization/Tables`
  (лицензия Apache-2.0). В репозитории русификатора лежит не копия этих таблиц, а список из примерно шестидесяти слов и
  тридцати имён монстров, на которые опирается перевод: `translation/official.tsv` и строки `+game` в
  `translation/ru/extra.tsv`.
- `python3 tools/official.py find 'truck'` показывает, как игра переводит слово; `dump` выгружает все её тексты;
  `check` сверяет наш список с таблицами (при первом запуске скачивает их в `~/.cache/rtk/REPOAssets`). После
  обновления игры `check` покажет, какие слова в ней изменились.
- `python3 tools/terms.py` проверяет, что прежние слова («точка извлечения», «грузовик», «хост»…) не вернулись в
  перевод; запускается вместе с `tests/langcheck.sh`.
- Имена монстров мод получает от игры по-английски и вставляет в свои фразы. Русское имя подставляется при выводе и
  только во фразах, помеченных `+names` (подпись угрозы, сигнал сторожевого поста, «Провокация», «Усмирение»), - в
  общем словаре имён нет, потому что «Reaper» или «Chef» может оказаться ником игрока.

Таблицы в зеркале студии - от 13 ноября 2026; в игре 0.5.3 (23 ноября) часть официального перевода уточняли, так что
отдельные слова в самой игре могут уже отличаться. Проверить можно по файлам игры: по описанию студии, её тексты лежат
таблицами TSV в `REPO_Data/StreamingAssets/Localization/Default/` (здесь этих файлов не было, `tools/official.py` читает
только зеркало).

## Сборка и проверка

Нужны bash, python3 и доступ в интернет при первом запуске (компилятор и Mono.Cecil скачиваются в `~/.cache/rtk`).

    bash tools/pack.sh        # сборка и архив в release/
    bash tests/run.sh         # патчер на учебном моде: 22 сценария (Unity для шрифта заменяет tests/unity)
    bash tests/stress.sh      # патчер на большой настоящей сборке
    bash tests/langcheck.sh   # словарь: каждая переведённая строка, фразы из tests/drawn.tsv, названия снаряжения,
                              # слова самой игры (tools/terms.py) и замена текстов в настоящих данных мода (dump/*.json)

Шрифт пересобирать не нужно, пока не меняется набор букв. Если понадобится: `tools/mkfont.py` (исходные шрифты - в его
описании), затем `tools/mkbundle.py modern.bundle mod/font/RepoRPG_RU.ttf mod/font/RepoRPG_RU.bundle` (нужны
`pip install UnityPy fonttools`; где взять `modern.bundle`, написано в самом скрипте).

## Новая версия на Thunderstore

1. Поднять номер версии в четырёх местах: `mod/manifest.json`, `src/Shared/Settings.cs`, `src/Patcher/Entry.cs`,
   `src/Runtime/Loc.cs` (последние два - `AssemblyVersion`); дописать `mod/CHANGELOG.md`.
2. `bash tools/pack.sh` - архив `release/RepoRPG_RU-<версия>.zip` уже имеет нужный Thunderstore вид (`manifest.json`,
   `README.md`, `CHANGELOG.md`, `icon.png` в корне).
3. <https://thunderstore.io/package/create/> → войти → выбрать команду `Ilya_lis` → загрузить архив → Submit.
   Имя (`name` в `manifest.json`) менять нельзя: с другим именем получится новый мод. Выложенную версию заменить
   нельзя, только выпустить следующую; README и CHANGELOG страницы можно править и без новой версии.

3. Вкладки, которых ещё не было на снимках при размере текста 110 %: Контракты, Магазин, Перки, экран уровня.
4. Названия предметов игры в списке «Пополнение» (мод получает их по-английски). Вкладка Debug.

Файл `*.blob` в корне - декомпилированный исходник мода, а папка `dump/` - его данные, выгруженные русификатором. По ним
делался перевод. Они принадлежат автору мода и в архив русификатора не входят; перед тем как делать репозиторий
открытым, их стоит убрать.
